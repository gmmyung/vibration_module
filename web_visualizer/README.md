# OFBGlove 점자 비주얼라이저

WiFi를 통해 실시간 점자 패턴을 시각화하는 웹 애플리케이션입니다.

## 🚀 빠른 시작

### 1. 서버 실행 (노트북)

```bash
# 프로젝트 디렉토리로 이동
cd web_visualizer

# 의존성 설치
npm install

# 웹 서버와 TCP/WebSocket 서버 동시 실행
npm run dev

# 또는 개별 실행:
# npm start          # 웹 서버만 (포트 3000)
# npm run server     # TCP/WebSocket 서버만 (포트 8080, 8000)
```

### 2. 핸드폰/ESP32 앱 연결

1. **같은 WiFi 연결 확인**
   - 노트북과 핸드폰/ESP32가 같은 WiFi 네트워크에 연결되어 있는지 확인

2. **TCP 서버 주소 확인**
   - 노트북에서 실행된 웹 페이지에서 "핸드폰 TCP 연결 정보" 섹션 확인
   - 표시된 TCP 서버 주소를 확인 (예: `192.168.1.100:8888`)

3. **핸드폰/ESP32 앱에서 TCP 연결**
   - 앱에서 TCP 클라이언트로 연결 설정
   - 서버 주소: 노트북 IP (예: `192.168.1.100`)
   - 포트: `8888`
   - GATT 호환 프로토콜로 점자 데이터 전송

4. **노트북에서 시각화 확인**
   - 노트북 브라우저에서 `http://localhost:3000` 또는 `http://[노트북IP]:3000` 접속
   - 실시간으로 들어오는 점자 패턴 확인

## 🔧 설정

### WebSocket 서버 설정

WebSocket 서버는 기본적으로 `localhost:8000`에서 실행됩니다.

### 4단계: 핸드폰/ESP32 앱에서 데이터 전송**
- 핸드폰/ESP32 앱에서 TCP 클라이언트로 연결
- 서버 주소: 노트북의 IP 주소 (예: 192.168.1.100)
- 포트: 8080
- GATT 호환 프로토콜로 점자 데이터 전송

### 포트 설정

- **웹 서버**: 3000번 포트 (React 개발 서버)
- **TCP 서버**: 8888번 포트 (ESP32 앱용)
- **WebSocket 서버**: 8888번 포트 (웹 클라이언트용)

## 📱 사용법

### 1. 점자 패턴 시각화
- 실시간으로 들어오는 점자 패턴이 2×3 그리드에 표시됩니다
- 각 점은 활성화/비활성화 상태를 색상으로 구분합니다

### 2. 데이터 수집
- 모든 점자 패턴이 자동으로 수집됩니다
- 통계 정보가 실시간으로 업데이트됩니다
- 데이터를 JSON 파일로 내보낼 수 있습니다

### 3. 연결 상태 모니터링
- WebSocket 연결 상태를 실시간으로 확인할 수 있습니다
- 연결이 끊어지면 자동으로 재연결을 시도합니다

## 🛠️ 문제 해결

### 연결 문제

1. **IP 주소 감지 실패**
   - "다시 시도" 버튼 클릭
   - 수동으로 IP 주소 입력

2. **핸드폰에서 접속 불가**
   - 같은 WiFi 네트워크 확인
   - 방화벽 설정 확인
   - IP 주소 정확성 확인

3. **WebSocket 연결 실패**
   - WebSocket 서버가 실행 중인지 확인
   - 포트 8000이 사용 가능한지 확인

### 네트워크 설정

```bash
# Windows에서 IP 주소 확인
ipconfig

# 방화벽 설정 (Windows)
# Windows Defender 방화벽에서 포트 3000, 8000 허용
```
